\subsection{Cálculo de la vecindad y construcción voraz}

Implementación vectorizada de $C(S)$ y de los pares \textsc{Swap} (Sección~\ref{subsec:recap_t1}), y de la construcción voraz inicial:

{\footnotesize
\begin{verbatim}
def _candidates(A, S):
    k = int(S.sum())
    not_S = np.logical_not(S)
    if k == 0:
        return np.where(not_S)[0], []
    deg_S = A[:, S].sum(axis=1)     # deg_S[v] = |N(v) intersect S|
    add_candidates = np.where(not_S & (deg_S == k))[0]
    swap_v = np.where(not_S & (deg_S == k - 1))[0]
    swap_pairs = []
    S_idx = np.where(S)[0]
    for v in swap_v:
        adj_mask = A[v, S_idx]
        non_adj = S_idx[np.logical_not(adj_mask)]  # único u en S no adyacente a v
        if len(non_adj) == 1:
            swap_pairs.append((int(v), int(non_adj[0])))
    return add_candidates, swap_pairs


def _greedy_construct(A, n, rng, seed_S=None):
    S = np.zeros(n, dtype=bool) if seed_S is None else seed_S.copy()
    while True:
        add_candidates, _ = _candidates(A, S)
        if len(add_candidates) == 0:
            break
        v = rng.choice(list(add_candidates))
        S[v] = True
    return S
\end{verbatim}
}

\subsection{Búsqueda Tabú con reinicio (Algoritmo~\ref{alg:tabu_ils})}

{\footnotesize
\begin{verbatim}
def tabu_ils(A, n, max_iterations=8000, tenure=10, stall_limit=200,
             perturb_frac=(0.1, 0.3), seed=None):
    rng = random.Random(seed)
    S = _greedy_construct(A, n, rng)
    best_S, best_size = S.copy(), int(S.sum())
    tabu_until = np.zeros(n, dtype=int)
    stall, it = 0, 0

    while it < max_iterations:
        it += 1
        add_candidates, swap_pairs = _candidates(A, S)

        if len(add_candidates) > 0:
            non_tabu = [v for v in add_candidates if tabu_until[v] <= it]
            pool = non_tabu if non_tabu else list(add_candidates)
            v = rng.choice(pool)
            S[v] = True
            stall = 0
        elif swap_pairs:
            non_tabu_pairs = [(v, u) for v, u in swap_pairs if tabu_until[v] <= it]
            pool = non_tabu_pairs if non_tabu_pairs else swap_pairs
            best_pair, best_gain = None, -1
            sample = pool if len(pool) <= 15 else rng.sample(pool, 15)
            for v, u in sample:
                S_try = S.copy(); S_try[u] = False; S_try[v] = True
                gain = len(_candidates(A, S_try)[0])
                if gain > best_gain:
                    best_gain, best_pair = gain, (v, u)
            v, u = best_pair
            S[u] = False; S[v] = True
            tabu_until[u] = it + tenure
            stall += 1
        else:
            u = rng.choice(list(np.where(S)[0]))
            S[u] = False
            tabu_until[u] = it + tenure
            stall += 1

        if int(S.sum()) > best_size:
            best_size = int(S.sum())
            best_S = S.copy()
            stall = 0

        if stall >= stall_limit:                 # Perturbación tipo ILS
            S_idx = np.where(S)[0]
            frac = rng.uniform(*perturb_frac)
            n_remove = max(1, int(len(S_idx) * frac))
            for u in rng.sample(list(S_idx), min(n_remove, len(S_idx))):
                S[u] = False
                tabu_until[u] = it + tenure
            S = _greedy_construct(A, n, rng, seed_S=S)
            stall = 0

    return best_S, best_size
\end{verbatim}
}

\subsection{Instancias: formato DIMACS}

Ambas instancias se distribuyen en formato ASCII estándar DIMACS, idéntico al utilizado en el Informe~1:

{\small
\begin{verbatim}
c C125.9.clq
p col 125 6963
e 1 2
e 1 5
...
\end{verbatim}
}

Donde \texttt{p col 125 6963} define un grafo de 125 vértices y 6\,963 aristas, y cada línea \texttt{e u v} define una arista entre los vértices $u$ y $v$. Los archivos completos (\texttt{keller4.clq}, \texttt{C125.9.clq}) y el código completo de los experimentos (\texttt{mcp\_tabu\_ils.py}, \texttt{run\_experiments.py}) están disponibles en el repositorio del proyecto, en \texttt{notebook\_metaheuristica/}.
